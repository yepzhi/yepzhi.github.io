# Lovelace Feynman Technologies S.A.P.I. de C.V.

Sitio corporativo institucional de **Lovelace Feynman Technologies**, la empresa matriz impulsora del desarrollo STEM en México y América Latina.

## Características
- **Diseño Glassmorphism Oscuro**: Paleta de colores cuántica ultra-premium (violeta, cian y rosa de neón).
- **Fondo de Constelación de Partículas**: Animación Canvas fluida en segundo plano.
- **Átomo de Lovelace**: Animación orbital del modelo atómico de Bohr interactivo al movimiento del mouse.
- **Quantum Wave Sandbox**: Laboratorio interactivo donde el usuario modula ecuaciones de onda y activa la resonancia cuántica a 5.0Hz para revelar el corazón matemático del universo.

## Tecnologías Utilizadas
- HTML5 Semántico
- CSS3 Moderno (CSS Custom Variables y Keyframe animations)
- Vanilla JavaScript (Canvas 2D Rendering)
- FontAwesome Icons (para el set de iconos premium)
