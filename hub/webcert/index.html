Estructura requerida del archivo Excel:
Para Validación Placement Test (Richmond Young Adults), incluye las siguientes columnas:
  • Nombre: Nombre del estudiante evaluado.
  • Apellido: Apellidos completos.
  • Puntaje o Score: Calificación numérica (ej: 86). ¡El nivel se calcula automáticamente si se omite!
  • Nivel o CEFR: Nivel acreditado (A0, Pre-A1, A1, A1+, A2, A2+, B1, B1+, B2, B2+, C1).
  • Fecha: Formato DD/MM/YYYY de evaluación.
Escala Young Adults oficial:
0-4: A0 · 5-10: Pre-A1 · 11-20: A1 · 21-30: A1+ · 31-40: A2 · 41-50: A2+ · 51-60: B1 · 61-70: B1+ · 71-80: B2 · 81-90: B2+ · 91-100: C1
Para Asistencia a Sesión, asegúrate de incluir las siguientes columnas:
  • Nombre: Primer nombre del asistente.
  • Apellido: Apellidos completos.
  • Evento: Nombre del taller o conferencia.
  • Fecha: Formato DD/MM/YYYY (ej: 24/08/2025).
  • Horas: Duración en horas (ej: 2).
