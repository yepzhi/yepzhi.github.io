Estructura requerida del archivo Excel:
Para Asistencia a Sesión, asegúrate de incluir las siguientes columnas:
  • Nombre: Primer nombre del asistente.
  • Apellido: Apellidos completos.
  • Evento: Nombre del taller o conferencia.
  • Fecha: Formato DD/MM/YYYY (ej: 24/08/2025).
  • Horas: Duración en horas (ej: 2).
Para Validación Placement Test, incluye las siguientes columnas:
  • Nombre: Nombre del estudiante evaluado.
  • Apellido: Apellidos completos.
  • Nivel o CEFR: Nivel acreditado (ej: B2 Upper Intermediate).
  • Puntaje o Score: Calificación (opcional, ej: 86 / 100).
  • Fecha: Formato DD/MM/YYYY de evaluación.
